# 餵食零韻・萬聖節 Trick or Treat

在零韻的圖書館餐廳抽食材、擺上九宮格盤子，收手送餐給零韻鑑定——每局零韻會開隨機要求，色香味達標得 Treat（超過很多是大滿足、傳說級），未達標吃 Trick，鳳梨落盤直接掀盤。相鄰材料有五行生剋，不能吃的東西會扣分。材料品質隨機（R／SR／SSR／UR，越高占越多格），分數 = 色香味星數 × 占格數 × 各種倍率；點材料可看詳情，抽過的材料記在食材圖鑑（存在瀏覽器 localStorage）。結算會發一張可以存圖的「萬聖節料理鑑定證書」。

**玩：** https://dr1090a.github.io/rein-trick-or-treat/

## 檔案

- `data.js` — 所有材料、容器、組合技、結局、隨機事件、trick 與數值。改文字和平衡只動這個檔。
- `game.js` — 遊戲邏輯（狀態機），只讀 `data.js` 的規則代號。
- `style.css`、`index.html` — 畫面。
- `assets/rein/` — 零韻表情立繪。

## 直播用

- OBS 瀏覽器來源可加 `?obs=1` 讓背景透明，或在頁面按 `T` 切換。
- 快捷鍵：空白鍵抽一樣、`R` 旋轉、`1`–`9` 放到第幾格、`Enter` 送餐。
